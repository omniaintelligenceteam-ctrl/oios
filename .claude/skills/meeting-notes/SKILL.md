# Meeting Notes

Turn raw, messy notes into a clean summary with clear action items.

## Trigger
User says things like: "clean up these notes", "summarize this meeting", "turn this into meeting notes", pastes a block of raw text

## Process

### Step 1: Receive the raw input
Wes will paste raw notes, a transcript, or a voice-to-text dump. Don't ask clarifying questions first — just process what's there.

### Step 2: Output clean notes

**Format:**
```
## [Meeting Title or Topic]
**Date:** [date if mentioned, otherwise leave blank]
**Attendees:** [if mentioned]

### Summary
[2-4 sentences. What was this meeting about and what was the outcome?]

### Key Points
- [Important thing discussed]
- [Another key point]

### Decisions Made
- [Decision 1]
- [Decision 2]

### Action Items
- [ ] [Task] — [Owner if mentioned] — [Due date if mentioned]
- [ ] [Task] — ...

### Open Questions / Parking Lot
- [Anything unresolved or tabled]
```

### Step 3: Flag anything unclear
After presenting the clean notes, note any parts of the raw input that were unclear or that Wes should verify.

Example: "Heads up — I wasn't sure if the 'Thursday deadline' referred to the proposal or the contract. You may want to confirm."

### Step 4: Offer follow-ups
Ask: "Want me to draft any of these action items, or send a recap to anyone?"

## Notes
- Keep the summary short. If someone wasn't in the meeting, they should understand it in 30 seconds.
- Action items must be specific and owned. "Discuss further" is not an action item.
- Don't editorialize — reflect what was said, not what should have been said.
