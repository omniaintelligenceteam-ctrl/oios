# Weekly Review

Run a quick weekly business review — what got done, what's stuck, and what matters most this week.

## Trigger
User says things like: "weekly review", "let's do a review", "help me review my week", "what should I focus on this week"

## Process

### Step 1: Pull context
Read the following files before asking anything:
- `context/current-priorities.md`
- `context/goals.md`
- Any recent entries in `decisions/log.md`

### Step 2: Ask Wes 4 questions (one message, not one at a time)

```
Quick weekly review — answer these however you want:

1. What got done this week?
2. What didn't get done that was supposed to?
3. Anything blocking you or feeling stuck?
4. Any new priorities, opportunities, or decisions that came up?
```

### Step 3: Generate the review output

**Format:**
```
## Weekly Review — [Week of Date]

### Wins
- [What got done]

### Carried Over
- [What didn't get done — no judgment, just facts]

### Blockers / Stuck Points
- [What's in the way]

### Priority Reset — This Week
1. [Top priority]
2. [Second priority]
3. [Third priority]

### Suggested Actions
- [Specific thing Wes could do to move the needle this week]
- [Another suggestion]

### Decision Log Entries to Add
- [Any decisions from this week worth logging]
```

### Step 4: Offer follow-ups
Ask: "Want me to update `context/current-priorities.md` based on this? Or log any of those decisions?"

## Notes
- Be honest in the "Carried Over" section. Don't soften it. Wes wants truth.
- The "Suggested Actions" should be concrete and doable — not vague advice.
- Keep the whole thing under one screen. This isn't a board report.
